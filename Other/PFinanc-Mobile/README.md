# PFinanc React Native Application

A production-grade React Native application serving as the Financial Command Center for families.

## Origin & Context
This project was migrated from a web-based HTML/CSS UI generated by Google Stitch (Aida) into a native React Native application. 
- **Original Source**: `Stitch-PFinanc` (HTML, Tailwind CSS)
- **Target**: Pure React Native components (Zero WebViews, Zero DOM rendering)

## Architecture
- **Framework**: Expo / React Native
- **Navigation**: React Navigation (Bottom Tabs & Native Stack)
- **Styling**: Native React Native `StyleSheet` backed by a unified Theme token system extracted from `DESIGN.md`.
- **Icons**: Lucide React Native (replacing Material Symbols Outlined from the web version).

## Directory Structure
- `src/theme/`: Extracted design tokens (Colors, Typography, Spacing, Shadows, Radius)
- `src/navigation/`: Route configuration and tab setups (`RootNavigator.tsx`)
- `src/components/`: Reusable, modular UI components (`cards/`, `navigation/`, `transactions/`, `accounts/`)
- `src/screens/`: High-level screen containers
- `src/services/mock/`: Mock data layers ensuring strict type-safety (`transactions.ts`)
- `docs/`: Markdown documents mapping Stitch screens to React Native components

## Semantic Guarantees
- **No WebViews**: The app relies exclusively on `<View>`, `<Text>`, `<ScrollView>`, and Native APIs.
- **Financial Types**: Floating-point math is avoided for currency limits. String amounts are strictly used in services to prevent floating-point anomalies.
- **UI Consistency**: Shadows, typography hierarchies, and layout structures have been accurately mapped from the original Tailwind definitions to React Native styles.

## Development
```bash
# Install dependencies
npm install

# Start the Expo Metro Bundler
npm run start
```
